Bottom line

The gate's detection is not uniform. A derived-view clause and a cleanly planted arithmetic dependent are caught every time in this sample; a copied description is never cut (five pointers, one reworded copy answered confirmed); and the neighbor item's factorytax result is a fixture failure, not evidence about the gate. Six clean controls produced no false positives. The next probe should re-run the factorytax neighbor with its anchored claim: if holds still arrives over a stale arithmetic value, the neighbor item is a rubber stamp in that shape; if it is fixed, run #6 measured a fixture, not a weakness.
